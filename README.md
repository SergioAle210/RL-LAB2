## Contexto del laboratorio

En este laboratorio se modela un sistema de despacho de ascensores hospitalarios mediante un Proceso de Decisión de Markov (MDP) con el propósito de optimizar el tiempo de atención, priorizar emergencias y reducir el consumo energético. Además, se analiza formalmente el modelo diseñado, se implementan desde cero los algoritmos de Policy Iteration y Value Iteration, y se comparan sus resultados para evaluar su desempeño y determinar su viabilidad como base para un futuro sistema inteligente de control de ascensores.
